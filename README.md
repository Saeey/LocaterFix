# Locater Fix · Locater 修复补丁

由 **for_null** 发布的《雨中冒险 2》独立兼容补丁，依赖并需启用官方原版 **Hyru-Locater 1.3.5**。修复标记更新空引用刷屏、保留标记颜色，并移除原版遗留的测试箱子生成钩子。原版作者为 **Hyru / Hyrulien**。

Source for the unofficial [Locater Fix companion plugin](https://thunderstore.io/c/riskofrain2/p/for_null/Locater_Fix/), published by **for_null**. The original [Locater](https://thunderstore.io/c/riskofrain2/p/Hyru/Locater/) is by **Hyru / Hyrulien** and remains a separate required dependency.

The patch stops Locater's static-marker `ChargeIndicatorController.Update` null-reference spam and removes its exact leftover test-chest scene postfix. It only supports the official Locater 1.3.5 DLL and checks its version and SHA-256 before applying patches. See [VALIDATION.md](VALIDATION.md) for the actual gameplay test and remaining limits.

## 构建 / Build

需要 .NET 8 SDK，以及自己安装的游戏和 BepInEx 引用。将 `Local.Paths.props.example` 复制为 `Local.Paths.props`，填写游戏 `Risk of Rain 2_Data/Managed` 和配置目录 `BepInEx/core` 两个路径，再执行下方命令。第三方引用 DLL 不放入仓库，也不复制到输出目录。

Install the .NET 8 SDK. Supply references from your own installed game and BepInEx profile; those third-party assemblies are not included or copied into the output.

Copy `Local.Paths.props.example` to `Local.Paths.props`, replace its two example paths, then run:

```console
dotnet build src/LocaterFix/LocaterFix.csproj -c Release
```

Alternatively pass `-p:GameManaged="<game>/Risk of Rain 2_Data/Managed" -p:BepInExCore="<profile>/BepInEx/core"` directly to `dotnet build`. The plugin is written to `src/LocaterFix/bin/Release/netstandard2.1/LocaterFix.dll`.

## 打包 / Package

新构建的 DLL 需要先进行游戏内验证，再使用下方标准工程打包命令。安装包仅收录明确列出的补丁 DLL、用户文档、许可证和新图标；源码、构建文件、第三方 DLL、日志和本机路径均与安装包分开。

After testing the newly built DLL in-game, create a Thunderstore ZIP with:

```console
dotnet build src/LocaterFix/LocaterFix.csproj -c Release -t:PackageRelease
```

The target copies an explicit allowlist of runtime files and documents into `artifacts/`. Source code, build scripts, game/BepInEx reference DLLs, machine-local paths and logs do not belong in the installation package. Keep staging output generated by this target separate from source material.

The 1.0.1 package is a packaging-only revision: it reuses the exact gameplay-tested plugin DLL from the original 1.0.0 package. Its BepInEx plugin version remains 1.0.0. The SDK build uses the same source, but is not byte-identical to the historical .NET Framework compiler output and has not itself been gameplay-tested. The `PackageRelease` target accepts `-p:ReleaseBinary="<path-to-tested-DLL>"` for this documented packaging-only case. Test any rebuilt DLL before publishing it as a runtime update.

## 仓库文件与安装包 / Repository and installation package

`src/LocaterFix` 存放源码及标准 `.csproj`；`thunderstore` 存放安装包元数据、介绍、更新日志和图标。`VALIDATION.md` 记录真实验证范围，`LICENSE` 为本补丁的 MIT 许可证。开发使用 AI 辅助，Thunderstore 已标注 AI Generated。仓库不分发原版 Locater 或游戏文件。

- `src/LocaterFix`: C# source and SDK-style `.csproj`.
- `thunderstore`: package metadata, user-facing README, changelog and the new icon.
- `VALIDATION.md`: precise verification history and limitations.

The source was developed with AI assistance; the Thunderstore package is tagged AI Generated. No original Locater code/assets or game assemblies are redistributed.

## 验证与限制 / Validation and limitations

Windows / RoR2 1.5.0#1224 下，已进行约 35 秒的单人第一关实测：生成 22 个彩色标记，可正常出舱，Ctrl+H 隐藏和恢复正常，本次日志中目标更新异常与 TESTING 箱子消息均为 0。购买后标记移除、跨关卡、联机和长时间游玩尚未验证。详见 [VALIDATION.md](VALIDATION.md)。

An approximately 35-second first-stage test on Windows / RoR2 1.5.0#1224 created 22 colored markers, allowed leaving the pod and verified Ctrl+H hide/show, with zero target updater exceptions or TESTING chest-spawn messages in that log. Purchase-related marker removal, stage transitions, multiplayer and long sessions remain untested.


源码与安装包已分开管理。配置两个本地引用路径后，用 `dotnet build` 构建标准 C# 工程。Thunderstore 安装包只收录运行插件和用户文档，不附带源码或构建脚本。1.0.1 仅调整打包与源码链接，沿用已实测的 1.0.0 插件 DLL；新工程编译产物尚未进游戏复测。
